# Falcão SH - Work

Sistema da Falcão SH Construções para **licitações de obras**:

- **Licitações**: busca diária no PNCP (Portal Nacional de Contratações Públicas) por palavras-chave e estados.
- **Documentos**: cofre de certidões com validade e alertas de vencimento.
- **Relatório de habilitação**: lê o edital (PDF/ZIP do PNCP ou enviado manualmente) e compara com o cofre.
- **Orçamentos**: orçamentador (SEINFRA-CE 028.1 desonerada / 028 onerada, BDI, encargos, cronograma, curva ABC, carta proposta, exportação Excel).

Tecnologia: Next.js + Supabase (banco, login e arquivos) + Vercel.
Acesso restrito aos e-mails cadastrados em **Empresa → Pessoas com acesso**.
